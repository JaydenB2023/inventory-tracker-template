# Inventory Tracker (Template)

A lightweight Flask application that demonstrates how internal inventory tools can be built using
Python, SQLAlchemy, and server-rendered templates.

This project is intended as a template and portfolio example, showcasing:
- CRUD operations (Create, Read, Update, Delete)
- UI-driven database interactions
- Filtering, sorting, and pagination
- Clean separation of templates and static assets

## Tech Stack
- Python
- Flask
- SQLAlchemy
- SQLite (default)
- HTML templates
- CSS

## Purpose
This repository is a sanitized template based on an internal tooling project.  
It is designed for local development and demonstration purposes and does not include
authentication or production security features. Database portion is not included.

## Run locally
1. Create virtual environment:
```bash
python -m venv .venv
```
2. Activate it:
```bash
source .venv/bin/activate
# Windows:
.venv\Scripts\activate
```
3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the app:
```bash
python app.py
```
